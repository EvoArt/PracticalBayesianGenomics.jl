PracticalBayesianGenomics.jl

PracticalBayesianGenomics.jl builds Bayesian genomic models on PracticalBayes.jl. Use bayes_alphabet_model for BayesB or BayesC marker regression, or animal_model for breeding values with pedigree or genomic relatedness. Each builder returns a model and a blocked Gibbs sampler compatible with AbstractMCMC.

Install the package and AbstractMCMC in the same Julia environment:

using Pkg
Pkg.add(url="https://github.com/EvoArt/PracticalBayesianGenomics.jl")
Pkg.add("AbstractMCMC")

Marker regression

Rows of X are individuals and columns are markers. Centre each marker column before fitting:

using PracticalBayesianGenomics, AbstractMCMC, Random, Statistics

rng = MersenneTwister(42)
X = randn(rng, 60, 12)
X .-= mean(X; dims=1)
y = 1.5 .* X[:, 3] .+ randn(rng, 60)

model, sampler = bayes_alphabet_model(y, X; variant=:C)
draw, state = AbstractMCMC.step(rng, model, sampler)
draw.δ  # one inclusion indicator per marker
draw.β  # marker effects

For an analysis, discard warm-up draws and summarize many later draws. The posterior mean of each δ is its inclusion probability. variant=:B selects the BayesB model.

Animal model

animal_model(y, X, Z, rel) uses phenotype vector y, fixed-effect design X, incidence matrix Z, and a RelatednessStructure. For pedigree relatedness, parents must precede offspring and 0 denotes an unknown parent:

using SparseArrays, LinearAlgebra

sire = [0, 0, 1, 1, 3, 3]
dam  = [0, 0, 2, 2, 4, 4]
rel = pedigree_relatedness(sire, dam)
Z = sparse(1.0I, 6, 6)
Xfixed = ones(6, 1)
phenotype = [1.2, 0.9, 1.5, 1.7, 2.1, 1.8]
animal, animal_sampler = animal_model(phenotype, Xfixed, Z, rel)

Use genomic_relatedness_from_markers to build a relatedness structure from a dosage matrix instead. Inspect the model and its priors before interpreting posterior estimates.

API reference

PracticalBayesianGenomics.AnimalKernel — Type
AnimalKernel(rel, ZtZ, Zt)

Gibbs kernel that samples the breeding-value block u from its exact multivariate-normal full conditional

u | rest ~ N(P⁻¹ b, P⁻¹),   P = Z'Z/σ²ₑ + K⁻¹/σ²ᵤ,   b = Z'(y − Xβ)/σ²ₑ.

rel::RelatednessStructure carries the precomputed K⁻¹; ZtZ = Z'Z and Zt = Z' are cached at build time. Per sweep only the precision P (which depends on the two current variances) is rebuilt and factorized once.

The kernel is mutable and caches the Cholesky symbolic factorization across sweeps. The precision's SPARSITY PATTERN is constant (only the two scalar variances change), so the expensive CHOLMOD symbolic-analysis / fill-reducing- ordering step (cholmod_l_analyze, profiled at ~30% of a sweep) is done ONCE and reused via in-place cholesky! every sweep afterwards. The precision is kept DENSE for a dense (genomic G⁻¹) K⁻¹ and SPARSE for a sparse (pedigree A⁻¹) one — the original broadcast sparse ./ s .+ dense ./ s silently returned a sparse matrix even for the dense genomic case, forcing the whole dense precision through the sparse CHOLMOD path (fill-in + re-analysis every sweep); dispatching on K⁻¹'s storage fixes that.

Prefer building this via animal_model rather than by hand.

PracticalBayesianGenomics.BayesAlphabetKernel — Type
BayesAlphabetKernel(xtx; variant=:C)

Gibbs kernel sampling the joint (β, δ) marker-effect block by a single-site Gibbs scan. xtx is the precomputed vector of column cross-products xⱼ'xⱼ (constant across sweeps). variant selects the alphabet member:

  • :C (default) — spike-and-slab with a COMMON effect variance σ²ᵦ shared by all included markers, and inclusion probability π (BayesCπ).
  • :B — spike-and-slab where included markers each get their own variance (here approximated by the shared-σ²ᵦ conditional; a full per-marker-variance BayesB is a later extension).

The kernel reads y, X from the model args and σ²ᵦ, σ²ₑ, π from the current state. Prefer building via bayes_alphabet_model.

PracticalBayesianGenomics.GaussianEffectKernel — Type
GaussianEffectKernel(name, XtX, Xt, Zt, prior_var)

Gibbs kernel that samples a Gaussian fixed-effect block name (here β) from its conjugate multivariate-normal full conditional under a N(0, prior_var·I) prior. XtX = X'X, Xt = X', and the cached sparse Zt = Z' are supplied at build time. The conditional precision is X'X/σ²ₑ + I/prior_var; the conditional mean solves that against X'(y − Zu)/σ²ₑ, with Zu done via the cached SPARSE Zt. For the small p typical of fixed effects this is a tiny dense solve, done in closed form so β needs no NUTS/AD step.

PracticalBayesianGenomics.InvGammaVarKernel — Type
InvGammaVarKernel(name, prior, ss; predictor=nothing)

An AbstractGibbsKernel (see PracticalBayes.gibbs_step) that resamples the variance-component block name from its conjugate Inverse-Gamma full conditional.

The model must place a name ~ InverseGamma(ν/2, ν·S²/2) prior on the variance (the scaled-inverse-χ²(ν, S²) parameterisation used throughout this package). prior = (ν, S²) names those same prior hyperparameters; the kernel adds the data's degrees of freedom and sum of squares and draws

name ~ InverseGamma((ν + n)/2, (ν·S² + SS)/2)

where n and SS come from the user's ss closure.

Arguments:

  • name::Symbol — the variance block this kernel owns and returns.
  • prior — (ν, S²): the prior degrees of freedom and scale, matching the InverseGamma(ν/2, ν·S²/2) written in the model body.
  • ss — the sufficient-statistics closure ss(c) -> (n, SS), given the ModelConditional c. n is the number of terms (residual d.f. or number of random effects) and SS their sum of squares. The closure does ALL model- specific work — it reaches into c.values / c.model.args itself — so this kernel imposes no assumptions about the model's data layout.

Example — residual variance of a linear model with mean μ = X·β:

k = InvGammaVarKernel(:σ²ₑ, (νe, Se2)) do c
    y = c.model.args.y
    X = c.model.args.X
    resid = y .- X * c.values.β
    (length(y), dot(resid, resid))
end
# ... spl = Gibbs(:σ²ₑ => k, :β => NUTS(0.8), ...)

PracticalBayesianGenomics.RelatednessStructure — Type
RelatednessStructure

Holds a precomputed inverse relatedness matrix Kinv (K⁻¹) and a kind label (:pedigree, :genomic, or :singlestep). Built ONCE via one of pedigree_relatedness, genomic_relatedness, or singlestep_relatedness; reused every Gibbs sweep by the animal model's u-block kernel, which never re-inverts K.

Kinv may be sparse (pedigree A⁻¹ from Henderson's rules) or dense (genomic G⁻¹); the kernel handles both — Z'Z/σ²ₑ + Kinv/σ²ᵤ stays sparse iff both terms are, and cholesky dispatches to the sparse or dense factorization accordingly.

PracticalBayesianGenomics.animal_model — Method
animal_model(y, X, Z, rel; β_scale=1e6, νu=3.0, Su2=1.0, νe=3.0, Se2=1.0)
    -> (model, sampler)

Build the animal model and a ready-to-use blocked-Gibbs sampler for it.

  • y — n-vector of phenotypes.
  • X — n×p fixed-effect design (intercept/covariates).
  • Z — n×q incidence matrix mapping records to the q animals in rel.
  • rel — a RelatednessStructure (pedigree_relatedness, genomic_relatedness, or singlestep_relatedness). Its K⁻¹ is precomputed once; the sampler reuses it every sweep.
  • β_scale— prior variance for the flat fixed effects.
  • (νu, Su2), (νe, Se2) — scaled-inv-χ² prior d.f./scale for σ²ᵤ / σ²ₑ.

Returns (model, spl). spl samples u with the exact MVN AnimalKernel, σ²ᵤ/σ²ₑ with conjugate InvGammaVarKernels, and β with NUTS (cheap for small p). Sample with AbstractMCMC.sample(model, spl, N) / AbstractMCMC.step.

The relatedness matrix K is written into the model body ONLY as the prior u ~ MvNormal(0, σ²ᵤ K) used for coverage/log-density bookkeeping; the actual u update never uses K (only the cached K⁻¹). For the pedigree case, where K = A is expensive to form densely, pass the model a dense K only if you need log-joint evaluation — otherwise the sampler runs entirely off K⁻¹.

PracticalBayesianGenomics.bayes_alphabet_model — Method
bayes_alphabet_model(y, X; variant=:C, b=1.0, c=1.0,
                     S2b=var(y)*0.1, S2e=var(y), νb=3.0, νe=3.0)
    -> (model, sampler)

Build a Bayesian-alphabet whole-genome regression and its blocked-Gibbs sampler.

  • y, X — n phenotypes and n×p (centred) marker matrix.
  • variant — :C (BayesCπ) or :B (see BayesAlphabetKernel).
  • (b, c) — Beta prior for the inclusion probability π.
  • (νb, S2b), (νe, S2e) — scaled-inv-χ² priors for σ²ᵦ / σ²ₑ.

Returns (model, spl). The (β, δ) block uses the single-site BayesAlphabetKernel; σ²ᵦ/σ²ₑ use conjugate InvGammaVarKernels; π uses PracticalBayes' conjugate Beta ConjugateGibbs. Sample with AbstractMCMC.sample(model, spl, N).

PracticalBayesianGenomics.genomic_relatedness — Method
genomic_relatedness(G; blend=0.0, base=I) -> RelatednessStructure

Build a dense genomic relatedness structure from a genomic relationship matrix G (e.g. VanRaden's G = MMᵀ / (2·Σpⱼ(1-pⱼ)) for centred marker matrix M). G⁻¹ is formed once here via a single Cholesky and reused every sweep.

blend > 0 returns (1-blend)·G + blend·base before inverting — the standard regularisation that keeps G invertible when markers make it singular/near- singular (base defaults to the identity, i.e. a ridge toward independence; pass a pedigree A restricted to the genotyped animals to blend toward pedigree instead). Use a small blend (e.g. 0.01–0.05) on real data.

source
PracticalBayesianGenomics.genomic_relatedness_from_markers — Method
genomic_relatedness_from_markers(M; centered=false, blend=0.01) -> RelatednessStructure

Convenience: build G from a raw n×p marker dosage matrix M (entries in {0,1,2}) using VanRaden's method 1, then delegate to genomic_relatedness. Columns are centred by 2pⱼ (allele frequencies estimated from M unless centered=true, meaning M is already centred) and G = ZZᵀ / (2·Σpⱼ(1-pⱼ)).

PracticalBayesianGenomics.inbreeding_coefficients — Method
inbreeding_coefficients(sire, dam) -> Vector{Float64}

Inbreeding coefficient Fᵢ of each animal, computed by the recursive tabular method (Fᵢ = ½·A[sire, dam], the numerator relationship between its parents). Only the relationship entries actually needed are computed, memoised in a small Dict, so this is far cheaper than forming the whole A. Parents must precede offspring (see pedigree_relatedness).

source
PracticalBayesianGenomics.pedigree_relatedness — Method
pedigree_relatedness(sire, dam) -> RelatednessStructure

Build the sparse inverse numerator-relationship matrix A⁻¹ directly from a pedigree, via Henderson's (1976) rules, WITHOUT ever forming the dense A. For a pedigree of q animals this is O(q) work and O(q) nonzeros — the reason the classic animal model scales to millions of animals where a dense A would not.

sire and dam are length-q integer vectors: sire[i] / dam[i] are the row indices (in 1:q) of animal i's parents, or 0 for unknown. Animals must be ordered so that parents precede offspring (a topological sort of the pedigree) — the standard requirement; sire[i] < i and dam[i] < i (or 0) for every i.

Returns a RelatednessStructure wrapping the sparse A⁻¹.

Henderson's rules: with inbreeding-adjusted Mendelian variances dᵢ = 1 / (½ - ¼(Fₛ + F_d)) (using Fₛ, F_d the parents' inbreeding coefficients, computed here via the recursive method), each animal contributes dᵢ to A⁻¹[i,i], -dᵢ/2 to the (i, parent) cells, and dᵢ/4 to the (parent, parent') cells for each present parent.

PracticalBayesianGenomics.singlestep_relatedness — Method
singlestep_relatedness(sire, dam, G, genotyped; blend=0.05, τ=1.0, ω=1.0)
    -> RelatednessStructure

Single-step (ssGBLUP) inverse H⁻¹, combining a full pedigree with a genomic relationship matrix on the subset of genotyped animals. Uses Aguilar/Legarra's closed form

H⁻¹ = A⁻¹ + [0 0; 0  τ·G⁻¹ − ω·A₂₂⁻¹]

where block 2 is the genotyped animals and A₂₂ is A restricted to them. G is blended toward A₂₂ (blend) for invertibility. τ, ω are the usual tuning weights (both 1 by default). genotyped is the vector of row indices (in the pedigree ordering) of the animals in G, in the same order as G's rows.

Requires the pedigree submatrix A₂₂, obtained by inverting the corresponding block of A⁻¹ (small: only the genotyped animals).
